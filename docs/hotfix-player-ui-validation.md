## Исправления интерфейса

- возвращена стабильная оболочка остальных разделов без постоянной боковой панели;
- плеер открывается как отдельный TV-экран;
- на широком экране слева находится компактная навигация, по центру — видео 16:9, справа — список каналов, снизу — горизонтальная лента каналов;
- на узких экранах список каналов и настройки открываются в отдельных диалогах и не сжимают видео;
- одинарное нажатие больше не переключает полноэкранный режим; используется двойное нажатие;
- в полноэкранном режиме доступны предыдущий канал, следующий канал, остановка и сворачивание;
- сохранена адаптивная политика восстановления буферизации для слабых TV Box;
- раздел «О приложении» доступен через меню разделов.
