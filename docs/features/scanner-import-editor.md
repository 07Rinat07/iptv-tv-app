# Сканер, импорт и редактор

Сканер ищет публичные M3U/M3U8 источники через поддерживаемые API и поисковые провайдеры. Его рабочая логика не изменяется этапами интерфейса и плеера.

Импорт поддерживает URL, файл, текст, Xtream Codes, Stalker Portal и другие подключённые провайдеры. Перед сохранением выполняется разбор M3U и удаление дубликатов.

Редактор работает с пользовательской копией, позволяет скрывать, удалять, переименовывать и перегруппировывать каналы, а также экспортировать M3U/M3U8/TXT.

Для расширения каталога сначала используйте готовые списки на стартовом экране, затем — сканер или ручной импорт.
