# Плеер и стартовый сценарий

## Запуск

Приложение открывает экран «Смотреть ТВ». На нём доступны:

- сохранённые плейлисты;
- встроенный каталог готовых URL;
- переход в сканер для поиска дополнительных источников.

Готовый источник импортируется только после выбора пользователя. После успешного импорта открывается плеер с конкретным `playlistId`.

## Воспроизведение

- Media3 используется как основной движок.
- LibVLC запускается один раз как fallback для неподдерживаемого контейнера, demux или кодека.
- Сетевые и HTTP-ошибки не запускают бессмысленный повтор через другой движок.
- `magnet:`, BitTorrent infohash и `.torrent` передаются встроенному libtorrent backend.
- Torrent TV `content_id` и live infohash передаются встроенному Ace Live runtime без автоматического fallback на установленный Ace Engine.
- При retry P2P-сессия и локальный HTTP stream создаются заново; при смене канала предыдущая подготовка отменяется через epoch и затем освобождается.
- Для поддерживаемого 1080p нет искусственного ограничения по размеру Java heap; окончательный выбор decoder остаётся за возможностями устройства.

## Текущий статус

Автономный Torrent TV маршрут подтверждён smoke-тестом на чистом эмуляторе, но Player ещё не прошёл релизную приёмку. На текущем этапе требуется сократить долгое/неуспешное переключение и обеспечить измеримую непрерывную подкачку встроенного live-буфера. На большинстве запустившихся каналов звук воспроизводится нормально. Подробности: [`../PLAYBACK_STATUS.md`](../PLAYBACK_STATUS.md).

## Управление

- одиночное нажатие показывает или скрывает панель;
- двойное нажатие переключает полноэкранный режим;
- Channel ± и media previous/next меняют канал;
- Home, End, Page Up и Page Down управляют длинными списками;
- выбранные канал, группа и подгруппа сохраняют фокус после фильтрации.
