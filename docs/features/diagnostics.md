# Диагностика

Раздел отображает состояние сети, runtime, плеера, Ace Stream и последние журналы приложения.

## Работа с логами

- фильтр по статусу, сообщению и `playlistId`;
- экспорт в Downloads или выбранный документ;
- кнопка «Сбросить старые ошибки» устанавливает новую временную точку журнала;
- записи до этой точки скрываются, а новые ошибки собираются отдельно;
- в базе хранится ограниченная выборка последних событий, поэтому старые записи постепенно вытесняются.

Сброс предназначен для воспроизведения новой проблемы без шума от предыдущих запусков.
