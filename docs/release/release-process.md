# Процесс релиза

## Автоматическая проверка

Ветка должна пройти основной Android CI: lint, unit-тесты, debug и release сборки.

## Подписанная сборка

Настройте переменные окружения:

```text
IPTV_RELEASE_STORE_FILE
IPTV_RELEASE_STORE_PASSWORD
IPTV_RELEASE_KEY_ALIAS
IPTV_RELEASE_KEY_PASSWORD
```

Затем выполните:

```bash
./gradlew --no-daemon :app:assembleRelease
```

Проверьте подпись и SHA-256. APK хранится в GitHub Release, а не в Git-репозитории.

## Release gate

- [ ] Android CI зелёный;
- [ ] контрольный набор обычных IPTV и Torrent TV источников без внешнего Ace Engine;
- [ ] серия из 20 переключений без зависшей предыдущей сессии и бесконечного ожидания;
- [ ] подтверждено непрерывное пополнение Torrent TV live-буфера и собраны rebuffer-метрики;
- [ ] звук и аудиодорожки проверены на всех запустившихся контрольных каналах;
- [ ] тест на слабом и среднем TV Box;
- [ ] двухчасовой тест;
- [ ] восьмичасовой soak-тест;
- [ ] слабая сеть;
- [ ] подпись APK;
- [ ] заполненный отчёт приёмки.

Текущий релизный gate не пройден: автономный маршрут подтверждён только коротким smoke-тестом одного live swarm, а переключение и подкачка ещё нестабильны. Детали — в [`../PLAYBACK_STATUS.md`](../PLAYBACK_STATUS.md).
