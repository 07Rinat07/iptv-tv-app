# Rinat IPTV — руководство пользователя

Этот документ описывает пользовательские сценарии, которые уже доступны в приложении. Он не обещает функции, которые ещё находятся в roadmap.

## Управление на Android TV / TV Box

- **D-pad / стрелки** — перемещение по элементам интерфейса.
- **Enter / OK / Center** — открыть выбранный элемент.
- **Back** — вернуться назад. В открытом каталоге Back возвращает ровно на один уровень иерархии.
- **Page Up / Page Down, Channel Up / Channel Down** — постраничная прокрутка там, где используется TV-список.
- **Мышь / тачпад / колесо** — поддерживаются в TV-friendly списках и кнопках.

## Мои плейлисты

1. Откройте раздел **«Мои плейлисты»**.
2. Выберите нужный плейлист кнопкой **«Выбрать»**.
3. Для просмотра структуры нажмите **«Открыть каталог»**.
4. Для технического редактирования обычного плейлиста используйте **«Открыть редактор»** / **«Редактировать»**.
5. Кнопка **«Открыть плеер»** открывает выбранный список без выбора конкретного канала в каталоге.
6. Системный список **«Избранное»** обновляется автоматически: его можно открыть как каталог или воспроизвести, но нельзя удалить, вручную обновить или открыть в редакторе как физический плейлист.

## Иерархический каталог

Каталог использует каноническую модель навигации и сохраняет происхождение элементов. Для существующих плейлистов путь обычно выглядит так:

`Источник → Плейлист → Группа / Подгруппа → Канал`

Модель также допускает `Каталог`, `Подкаталог` и виртуальные объединённые разделы. Системное **«Избранное»** уже является реальным виртуальным aggregate view: физическая строка плейлиста для него не создаётся.

### Breadcrumb / текущий путь

В верхней части каталога отображается текущий путь через разделитель `›`. Он показывает, в каком источнике, плейлисте и группе находится пользователь.

### Переход внутрь

- Выберите группу или другой контейнер и нажмите **OK / Enter** — откроется следующий уровень.
- Канал является конечным элементом (`leaf`) и не открывает ещё один уровень.
- Выбор канала передаёт в Player конкретный playback context, поэтому воспроизведение начинается именно с выбранного канала.

### Back

В каталоге кнопка **«Назад на один уровень»**, аппаратная Back и верхняя кнопка приложения **«Назад»** используют одну модель возврата:

- из группы — в плейлист;
- из подгруппы — в родительскую группу;
- из плейлиста — к источнику;
- на корне источника следующий Back закрывает каталог и возвращает к обычному экрану плейлистов.

Back не должен перескакивать через несколько уровней сразу.

## Восстановление focus после Player

Каталог запоминает focus по стабильному каноническому идентификатору, а не только по позиции строки в списке.

После возврата из Player приложение:

1. возвращается в ранее открытый уровень каталога;
2. прокручивает длинный список к сохранённой строке, если она вне экрана;
3. восстанавливает focus на ранее выбранном канале/элементе, если этот элемент всё ещё существует.

Если плейлист успел обновиться и прежняя группа или канал исчезли, приложение не сохраняет невалидный путь: оно возвращается к самому глубокому оставшемуся корректному уровню и выбирает актуальный focus target.

## Импорт и Scanner

- Пользовательские M3U/M3U8 и поддерживаемые источники добавляются через **«Импорт»**.
- **Scanner** ищет публичные кандидаты и передаёт подтверждённый результат в существующий import flow.
- Иерархический каталог и unified Favorites не изменяют Scanner discovery/query policy и не выполняют массовый сетевой probing каналов.

## Избранное

**«Избранное» — самостоятельная пользовательская библиотека каналов**, а не только набор ссылок на строки исходных плейлистов.

Когда канал добавляется в Избранное:

- приложение вычисляет общую logical identity через `ChannelStableIdentity`;
- сохраняет durable snapshot канала и известные source variants;
- один и тот же логический канал из нескольких источников остаётся одним favorite, а варианты источника сохраняются;
- удаление исходного плейлиста или его channel row не удаляет favorite;
- повторный импорт совпадающего канала снова делает live variant доступным без создания второго favorite;
- если живой источник отсутствует, Player может использовать сохранённый persisted variant/snapshot;
- representative favorite ID остаётся стабильным для текущей совместимости UI/Player.

### Виртуальный список «Избранное»

В **«Мои плейлисты»** автоматически отображается системный список **«Избранное»**.

- это виртуальный aggregate view, а не физический импортированный плейлист;
- он автоматически отражает текущую библиотеку Favorites;
- его можно открыть через **«Открыть каталог»** или **«Открыть плеер»**;
- кнопки физического обновления/удаления и редактор для него недоступны;
- внутри используются тот же canonical catalog и существующий Player runtime, отдельный плеер для Favorites не создаётся.

### Экспорт

На экране Favorites уже доступны TXT и M3U8 export representative каналов. M3U8 предназначен для совместимости с обычными IPTV-приложениями и устройствами.

Полный переносимый backup с сохранением logical identity, provenance и всех source variants является следующим отдельным roadmap-инкрементом. Обычный M3U/M3U8 не должен считаться полной резервной копией внутренних Favorites metadata.

## Player

При выборе канала из каталога используется точный маршрут выбранного канала. Для системного Favorites aggregate существующий Player получает выбранный live или persisted source variant через общий repository contract. После выхода из Player навигационный checkpoint каталога остаётся доступным для восстановления пути и focus.

## Диагностика

Если канал не запускается или приложение ведёт себя нестабильно:

1. откройте **«Диагностика»**;
2. проверьте сетевое состояние и последние технические сообщения;
3. для проблем P2P/Torrent TV учитывайте, что временная доступность swarm является динамическим состоянием и не должна удалять канал из каталога;
4. не очищайте плейлист только из-за временного playback failure — сначала проверьте источник и повторите запуск.

## Где найти встроенную справку

Краткая версия этого руководства находится прямо в приложении: **«Разделы» → «О приложении» → «Справка: каталог и Избранное»**.
