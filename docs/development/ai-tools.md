# Инструменты индексации

Каталог `tools/ai` используется для офлайн-подготовки индекса публичных плейлистов. Результат можно импортировать в диагностику как JSONL, отфильтровать по HTTP-статусу и числу `EXTINF`, затем вручную добавить выбранный URL.

Эти инструменты не заменяют встроенный сканер и не должны автоматически публиковать или импортировать непроверенные источники.
