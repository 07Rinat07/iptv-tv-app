# Stage 11: TV UI, Player Navigation And Low-Memory Hardening

## Цель этапа

Обновить оболочку приложения и экран просмотра под Android TV/TV Box, оптическую мышь,
тачпад и обычный сенсорный ввод, сохранив без изменений работающие механизмы сканирования
и поиска плейлистов.

## Защищённая область

В рамках этапа запрещено изменять:

- `feature/scanner/**`;
- `core/network/**`;
- `ScannerRepository`;
- `SearchPlaylistsUseCase`;
- источники, фильтрацию и ранжирование результатов поиска.

Перед упаковкой выполняется SHA-256-сверка этих файлов с исходной копией проекта.

## Реализовано

### 1. Адаптивная оболочка приложения

- На широком экране добавлена постоянная левая панель разделов.
- Панель можно свернуть до компактного режима.
- На узком экране сохранено диалоговое меню разделов без горизонтального переполнения.
- Текущий раздел остаётся видимым в верхней панели.
- Кнопки навигации имеют увеличенные области фокуса для пульта и мыши.
- Добавлен отдельный раздел `О приложении`.

### 2. Экран плеера

- Основная область видео переведена на формат `16:9`.
- Двойной клик мышью или двойное касание переключает обычный и полноэкранный режим.
- Кнопка `Назад` в полноэкранном режиме сначала сворачивает видео.
- Добавлены явные кнопки предыдущего и следующего канала.
- В полноэкранном режиме отображаются название канала, часы и быстрые действия.
- Редко используемые панели остаются сворачиваемыми через раздел `Вид`.

### 3. Плейлисты, группы и каналы

- Добавлена единая панель браузера каналов.
- Поддержан путь `Плейлист / Группа / Подгруппа`.
- Плейлисты, группы и подгруппы выбираются из горизонтальных списков.
- Поиск выполняется внутри открытого плейлиста.
- Список автоматически прокручивается к выбранному каналу.
- Строка канала показывает логотип, группу, избранное и компактную EPG-информацию.
- Добавлены понятное пустое состояние и адаптивная высота списка.
- Сохранены существующие полная каталогизация, избранное, EPG и multiview.

### 4. Пульт, мышь и тачпад

- `Channel +/-` и media previous/next переключают каналы.
- В полноэкранном режиме стрелки вверх/вниз переключают канал.
- `F` переключает полноэкранный режим.
- `Menu` и `Guide` возвращают к панели каналов.
- `Enter` и центральная кнопка D-pad запускают выбранный канал.
- Page Up/Page Down/Home/End продолжают управлять длинными списками.

### 5. Адаптивная буферизация

- Добавлена классификация устройства по CPU и доступному Java heap.
- Временной буфер и лимит памяти уменьшаются на слабых TV Box.
- Для multiview применяется отдельный уменьшенный бюджет каждого плеера.
- Политика восстановления после долгой буферизации хранится в playback session.
- Количество автоматических повторов ограничено, чтобы не создавать цикл `stop/prepare`.
- Текущий расчёт буфера отображается в технической информации плеера.

## Матрица приёмки на устройстве

| Сценарий | Ожидаемый результат |
|---|---|
| Двойной клик по видео | Полный экран; повторный двойной клик возвращает обычный режим |
| Back в полном экране | Плеер сворачивается, приложение не закрывается |
| Channel +/- | Переключается предыдущий/следующий канал |
| Menu/Guide | Открывается обычный экран со списком каналов |
| Мышь/тачпад | Клики и прокрутка работают без потери фокуса |
| Узкий экран | Видео и список располагаются вертикально без обрезания |
| Широкий экран | Видео и браузер каналов располагаются рядом |
| Слабый TV Box | Буфер ограничен, multiview не получает чрезмерный memory budget |
| Сканер | Результаты и механизм поиска совпадают с исходной версией |
