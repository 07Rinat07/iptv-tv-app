# Ace Stream

Приложение распознаёт `acestream://`, `ace://`, Content ID, magnet, `.torrent`, `.acelive` и локальные Engine URL.

Интеграция использует официальный Android Service/AIDL контракт:

1. обнаружение установленного Ace Stream Media/Engine;
2. `bindService`;
3. запуск и ожидание готовности движка;
4. получение локального HTTP endpoint;
5. передача разрешённого потока в основной плеер.

Если движок отсутствует или не отвечает, пользователь получает диагностируемую ошибку без бесконечного цикла повторов.
