# Catalog navigation hardening

## Реализовано

- Единая правая панель прокрутки для длинных вертикальных списков.
- Постраничные кнопки вверх и вниз с крупными TV-friendly областями нажатия.
- Кнопка возврата в начало списка, которая активируется после значительной прокрутки.
- Сохранена стандартная прокрутка колесом мыши, тачпадом, сенсорным экраном и D-pad-фокусом.
- Перетаскиваемый индикатор прокрутки остаётся доступным на широких экранах.
- Для горизонтальной временной шкалы EPG добавлены возврат в начало и постраничное перемещение влево/вправо.
- Время EPG отображается в системной временной зоне устройства вместо жёстко заданного региона.

## Каталог плейлистов

- Поиск по названию, источнику и типу плейлиста.
- Отображение количества найденных элементов.
- Сортировка: текущий сначала, по имени, по времени обновления и по числу каналов.
- Стабильные ключи элементов и детерминированный порядок при одинаковых значениях.
- Отдельное состояние, когда плейлисты существуют, но фильтр не дал результатов.

## Избранное

- Поиск по названию канала, группе и `tvg-id`.
- Сортировка: выбранный сначала, по имени, по группе и по доступности.
- Автоматический выбор первого видимого элемента после фильтрации.
- EPG, раскрытие программы, воспроизведение и экспорт сохранены.
- Время программы берётся из временной зоны устройства.

## Управление

- Пульт: D-pad перемещает фокус; кнопки постраничной прокрутки доступны через фокус и OK.
- Мышь и тачпад: колесо, перетаскивание скроллбара и нажатие навигационных кнопок.
- Сенсорный экран: стандартный свайп и крупные кнопки не менее 48 dp.
- Маленькие экраны: панель не показывается, если список не прокручивается; контент не перекрывается.
