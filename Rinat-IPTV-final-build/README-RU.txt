Rinat IPTV — финальная проверенная сборка

Содержимое:
1. Rinat-IPTV-final-debug.apk — APK для установки на Android TV / TV Box.
2. Rinat-IPTV-final-debug.apk.sha256 — контрольная сумма SHA-256.

Как установить:
1. Распакуйте ZIP-архив.
2. Скопируйте APK на Android TV / TV Box.
3. Разрешите установку приложений из неизвестных источников для файлового менеджера.
4. Откройте APK на Android-устройстве и подтвердите установку.

Важно для Ubuntu/Linux:
Не запускайте APK на компьютере через Java. APK предназначен для Android.
Если браузер пытается открыть файл, используйте правую кнопку мыши по ссылке:
«Сохранить ссылку как…», затем распакуйте ZIP через файловый менеджер.

Проверка SHA-256 в терминале:
sha256sum Rinat-IPTV-final-debug.apk
