# Changelog

Все значимые изменения проекта фиксируются в этом файле.

## Unreleased

### Added
- Стартовый экран просмотра с сохранёнными и готовыми списками каналов.
- Быстрый переход из готового списка непосредственно в плеер.
- Сброс старых ошибок и начало нового диагностического журнала.
- Автономный Ace Live маршрут для Torrent TV `content_id` и live infohash без автоматического запуска внешнего Ace Engine.
- Поддержка стандартного и Ace-расширенного HAVE, compact live status и скользящего live-window во встроенном peer-wire runtime.

### Changed
- Главный сценарий приложения теперь начинается с просмотра ТВ, а сканер остаётся дополнительным разделом.
- Документация объединена по назначению вместо набора файлов `stage*` и `hotfix*`.
- APK публикуются через GitHub Actions и больше не хранятся в репозитории.
- P2P retry полностью пересоздаёт сессию, stall ограничен watchdog, а переключение канала освобождает предыдущий локальный stream.
- LibVLC fallback ограничен ошибками контейнера, demux и кодека; сетевые/source ошибки не запускают второй заведомо бесполезный плеер.
- Снято искусственное ограничение разрешения Media3, из-за которого поддерживаемый 1080p мог отбрасываться на устройствах с небольшим Java heap.

### Known issues
- Переключение каналов бывает долгим и иногда завершается ошибкой.
- Встроенная подкачка Ace Live не на всех источниках удерживает достаточный запас данных; некоторые потоки тормозят, зависают или не открываются.
- На большинстве запустившихся каналов звук нормальный; единичные проблемы аудиодорожек остаются в матрице проверки.
- Стабильный релиз заблокирован до короткой матрицы каналов, тестов слабой сети и двухчасового/восьмичасового soak.

### Removed
- Кнопка внешней отправки письма из раздела «О приложении».
- Временные CI workflow завершённых этапов.
- Дублирующие каталоги с debug APK.

## 0.1.0 — 2026-08-06

- Ace Stream Android Service/AIDL.
- Media3 с LibVLC fallback.
- Адаптивный TV-интерфейс и полноэкранный плеер.
- Навигация каналов, групп и подгрупп с фокусом и Page Up/Page Down.
- Адаптивная буферизация для слабых TV Box.
- Автоматические lint, unit, debug и release проверки.
